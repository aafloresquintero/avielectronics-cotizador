\# Cotizador Yura Snacks



Herramienta web sencilla para calcular al instante el total de un pedido de AVI ELECTRONICS (Pizarras Interactivas para centro de reuniones de empresas y universidades) mientras se conversa con el cliente por WhatsApp.



\## Qué hace



\- Elige el modelo y la cantidad (de acuerdo a la cantidad se aplica un descuento al cliente)

\- Calcula el total y muestra el resumen del pedido.

\- Copia el resumen con un botón, listo para pegar en WhatsApp.



\## Cómo usarla



Abre la página desde el celular, completa los tres campos, toca "Calcular" y luego "Copiar resumen".



\## Cómo cambiar precios



Todos los precios y descuentos se muestran, al inicio del bloque de script de `index.html`, en las listas `PRODUCTOS` y `CANTIDAD`. Cambia ahí los valores y se actualiza la lista desplegable y el cálculo.



\## Tecnología



Una sola página HTML con CSS y JavaScript incluidos. No usa servidor, base de datos ni librerías externas.



\## Limitaciones actuales



\- Cotiza un solo producto por pedido.

\- Los precios se editan directamente en el código.
